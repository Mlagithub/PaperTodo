# 意图陈述：PaperTodo「晶透 / 水晶玻璃 (Crystal Glass)」高级皮肤

- **创建时间**: 2026-03-30
- **当前状态**: 已确认 (Confirmed)
- **灵感参考**: [Glance (lulu-loopp/glance)](https://github.com/lulu-loopp/glance) 物理光学与磨砂玻璃设计

## 1. 核心意图梳理

- **Outcome (目标交付)**：在 PaperTodo 中新增一款名为「晶透 / 水晶玻璃 (Crystal Glass)」的独立高级皮肤，融合 GlancePC 级别的物理立体光影、边缘高光与通透质感。
- **User (服务对象)**：追求桌面极致美感、喜欢高通透毛玻璃、晶莹水晶与桌面壁纸融合体验的 PaperTodo 用户。
- **Why now (核心诉求)**：现有默认纸片偏扁平实用，缺少像 GlancePC 那样具备物理边缘高光、立体厚度和鲜活通透感的现代桌面视觉质感。
- **Success (验收标准)**：
  1. **立体光影**：便签边缘呈现 135° 斜向渐变边缘高光切线（Rim Light），配合多层微内阴影与反弹光，形成实体水晶厚度感；
  2. **高透与鲜活**：背景柔化通透且色彩提纯（不发灰、不发脏），以纯净无色水晶（深色黑透 / 浅色白透）为主基调，兼顾微彩色透光琉璃感；
  3. **文字可读性**：正文文字与背景形成充分反差，无论处于何种复杂壁纸上方，文字均清晰舒适不累眼；
  4. **全态贯通**：展开便签窗口与贴边 Edge 胶囊均拥有统一的水晶玻璃质感。
- **Constraint (核心约束)**：
  1. 作为独立可选皮肤（与纸片、描图纸、Aero、像素风并列），不破坏其他皮肤与低配实色回退；
  2. 保持 PaperTodo 既有的亚毫秒级输入节拍与 120Hz 丝滑拖拽，不在每次按键时重算昂贵模糊；
  3. 严格遵守 PaperTodo 材质与窗口架构（D-051），不影响窗口交互尺寸与命中判定。
- **Out of scope (明确不做)**：
  1. 不重写整套 WPF 文本编辑内核，不改动 Markdown 语法解析；
  2. 不强行在旧版不支持 DWM 复合的系统上强开透明；
  3. 不将这种高透玻璃强加为默认皮肤，用户需在设置中自主选用。

## 2. 关键设计考量与技术方向

1. **材质系统集成**:
   - 在 `AppState.PaperSkin` 中增加 `Crystal` 标识；
   - 在 `MaterialPalette.cs` 中增加针对水晶玻璃的专用色盘（高光密度、原生 tint、表面微反射）；
   - 在 `SkinBorder.cs` 中实现专属的水晶光影绘制（135° 边缘光弧、内高光、背光反弹微光）。
2. **通透度与防灰防脏**:
   - 避免使用简单灰度半透明；利用加权色彩提纯，配合半透明衬底保护文字，保证任何壁纸下字迹清晰锐利。
3. **Edge 胶囊联动**:
   - 胶囊折叠态同样具备水晶切割倒角感与高透效果，与展开纸片保持高度连贯的视觉隐喻。
